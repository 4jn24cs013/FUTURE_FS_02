Mini-CRM – Client Lead Management System

Project Description

Mini-CRM is a web-based application used to manage client leads. It helps users add, view, search, edit, update lead status, and delete leads.

Features

- Add new leads
- View total leads
- Update lead status to Contacted or Converted
- Search leads by name
- Edit lead details and follow-up dates
- Delete leads
- Store data in a MySQL database

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: MySQL

How to Run

1. Install Node.js and MySQL.
2. Open the project folder in VS Code.
3. Install dependencies using "npm install".
4. Start the backend using "node backend/server.js".
5. Open "http://localhost:5000" in your browser.

Database

Database name: "mini_crm"
